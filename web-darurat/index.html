Sistem Sedang Offline

Mohon maaf, layanan SIAKANUDA saat ini sedang tidak dapat diakses.

Kenapa ini terjadi?
Karena SIAKANUDA berjalan secara mandiri menggunakan server fisik yang berada di gedung sekolah, maka jika koneksi internet atau aliran listrik PLN di sekolah mengalami gangguan (pemadaman), sistem ini otomatis akan ikut offline.
Instruksi Khusus untuk Siswa PKL:
Ketua PKL dan Anggota PKL tetap harus melakukan absensi secara manual dengan menuliskan kegiatan di buku jurnal fisik dan menyimpan dokumentasi (foto) terlebih dahulu di HP masing-masing.

Nanti jika sistem sudah kembali online, akan ada pemberitahuan dari WhatsApp SIAKANUDA untuk meng-input-kan data tersebut ke dalam sistem.

Sistem akan otomatis kembali beroperasi sesaat setelah aliran listrik kembali normal. Terima kasih atas pengertiannya.
